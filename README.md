# Zapeo

Reproductor de listas M3U para Android TV y Google TV. La app no incluye ningún canal: cada persona carga su propia lista.

Cada vez que se sube un cambio a este repositorio, GitHub compila el APK y lo publica en **Releases**.
Enlace fijo a la última versión: `https://github.com/zapeo-app/Zapeo/releases/latest/download/zapeo.apk`
